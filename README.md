# mikaevnikita.github.io

Фотогалерея на [Astro](https://astro.build), деплоится на GitHub Pages: https://mikaevnikita.github.io

## Как добавить фото

1. Положите оригиналы (JPG, PNG, TIFF) в папку `originals/`. Она есть только у вас локально и на GitHub не попадает.
   **Папка — это альбом, имя файла — название фото:**
   ```
   originals/
     Abstract/
       The Theater of Absurd.jpg   → альбом «Abstract», фото «The Theater of Absurd»
     Street/
       Red Market.jpg
     DSC02537.jpg                  → без альбома (только во «All») и без подписи
   ```
   - Порядок — по имени. Чтобы задать его явно, начните имя с номера: `01 Street`, `02 The Theater of Absurd.jpg`. Номер в название не попадает.
   - Имена с камеры (`DSC…`, `IMG_…`) подписью не показываются.
2. Запустите `npm run photos`. В `src/photos/` появятся WebP-мастера с той же структурой папок: длинная сторона до 2560 px, качество 92, поворот по EXIF, sRGB, без метаданных (включая GPS). Уже сконвертированные фото пропускаются.
   Скрипт ничего не удаляет, поэтому после конвертации оригиналы из `originals/` можно стереть: WebP останутся.
   Можно взять фото и из другой папки: `npm run photos -- ~/Pictures/export`. Они лягут в корень `src/photos/`.

В конце `npm run photos` проверяет `src/photos/` на дубли: если один и тот же кадр лежит в нескольких местах (под разными именами или в разных альбомах), выводится предупреждение со списком файлов. Сравнивается содержимое картинки, а не имя.

**Переименовать, перенести в другой альбом или удалить фото** нужно прямо в `src/photos/`: имена WebP-файлов и папок там и есть названия на сайте. Если сделать это в `originals/` и снова запустить `npm run photos`, появится дубль под новым именем.
3. `git add . && git commit -m "new photos" && git push`. Сайт обновится сам.

При сборке из мастеров нарезаются размеры для сетки (480–1600 px, качество 80) и для полноэкранного просмотра (1280–2560 px, качество 85), браузер выбирает нужный по экрану. Настройки лежат в `scripts/photos.mjs`, `src/lib/gallery.ts`, в начале `src/components/Gallery.astro` и в `astro.config.mjs`.

## Контакты

Ссылки в блоке «Contact me» задаются в массиве `CONTACTS` в `src/lib/gallery.ts`.

## Альбомы и SEO

У каждого альбома своя страница: папка `01 Street` → `/street/`, `05 Landscape∕Nature` → `/landscape-nature/`. Страницы и `sitemap.xml` (с фото для Google Images) собираются автоматически. Старые ссылки вида `/?album=street` перенаправляются на новые.

Заголовок и описание страницы альбома для поисковиков задаются в `ALBUM_SEO` в `src/lib/gallery.ts`; для альбома без записи там они собираются по шаблону.

Превью ссылки в мессенджерах и соцсетях — JPEG **1200×630**, кадрируется вручную:
- `public/og.jpg` — для главной и альбомов без своего превью;
- `public/og/<адрес альбома>.jpg` — для альбома, например `public/og/street.jpg`.
